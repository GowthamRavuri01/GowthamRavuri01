## Featured Projects

### 1. RAGNYS — Refining Information into Knowledge

**AI-Powered Document Intelligence & Retrieval-Augmented Generation**

An AI-powered document intelligence application designed to transform complex PDF documents into structured, searchable knowledge and support natural-language question answering through semantic retrieval and locally hosted language models.

**Key Highlights**
- Developed a document-processing workflow involving PDF parsing, text cleaning, document structure analysis, layout-aware grouping, and knowledge unit generation.
- Integrated Sentence Transformers using `sentence-transformers/all-MiniLM-L6-v2` to generate 384-dimensional text embeddings.
- Used PostgreSQL with pgvector for vector storage and semantic similarity search.
- Integrated Ollama with the `qwen3.5:4b` model for local LLM inference.
- Worked with a FastAPI-based backend and React-based interface to connect document-processing and retrieval workflows.
- Explored the integration of document intelligence, semantic retrieval, and LLM-based answer generation in a single application.

**Technologies:** Python, Sentence Transformers, RAG, Embeddings, Semantic Search, PostgreSQL, pgvector, Ollama, FastAPI, React, TypeScript.

**Repository:** [Explore RAGNYS](https://github.com/GowthamRavuri01/RAGNYS)
